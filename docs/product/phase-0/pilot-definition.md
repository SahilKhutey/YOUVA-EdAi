# YOUVA EdAI — Phase 0 Pilot Definition & Access Requirements

## 1. Pilot Cohort Criteria
- **Model:** B2B School-First (Single Classroom).
- **Target Size:** Exactly 25–30 students.
- **Grade:** Middle School (Grade 7 or 8).
- **Educator:** 1 Lead Mathematics Teacher with daily instructional authority.
- **Observer:** 1 Mathematics Department Head or Academic Supervisor.

## 2. Pilot Access Evidence Requirements
Before D03 (Launch Model) is locked, the following evidentiary items must be verified:
- [ ] Named Partner School identified with formal interest.
- [ ] Written confirmation of pilot classroom access.
- [ ] Confirmed teacher participation in the daily override loop.
- [ ] Access to school computer lab or student-accessible devices confirmed.
- [ ] Parent consent collection pathway defined with school administration.
